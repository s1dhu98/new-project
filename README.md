Smiling Emoji — Interactive CSS

This small demo shows a responsive, interactive smiling emoji built with pure HTML, CSS and a tiny amount of JavaScript.

How to use

- Open `index.html` in your browser (double-click or right-click -> Open with).
- Use the color picker to change the face color.
- Use the size slider to resize the emoji.
- Click the face or press Enter/Space when focused to animate.
- Use the Wink and Animate buttons for quick interactions.
- Toggle "Auto-blink" to let the emoji blink periodically.

Notes

- The demo is intentionally dependency-free and works offline.
- It's responsive and adapts layout for small viewports.
- If you want additional features (stick-out tongue, more expressions, or an SVG mouth), tell me and I can extend it.
